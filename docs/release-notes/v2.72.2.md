## 수정

- 와일드카드(`*.example.com`)로 등록했거나 대문자가 섞인 도메인의 호스트에서, 로그 상세의 "이 호스트만" 정책 비활성화가 "Proxy host not found for domain" 오류로 실패하던 문제를 고쳤습니다. 로그 상세의 URI 차단도 같은 이유로 실패했는데, 함께 고쳤습니다.

---

> ```bash
> docker compose pull && docker compose up -d
> ```

## Fixes

- On a host registered with a wildcard (`*.example.com`) or a domain containing capital letters, disabling a rule for "this host only" from the log detail failed with "Proxy host not found for domain". Blocking a URI from the log detail failed for the same reason. Both now work.
