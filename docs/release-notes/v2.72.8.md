## 수정

- 사이트가 직접 준 403이 로그에 "봇 필터" 차단으로 표시되었습니다. 그래서 사이트가 Google 광고 크롤러에 403을 주면 NPG가 막은 것처럼 보였습니다. 이제 NPG가 직접 막은 요청에만 봇 필터로 표시됩니다.
- 설정 → 봇 필터에서 봇 목록을 저장해도 nginx에 바로 반영되지 않았습니다. 이제 저장하면 모든 호스트에 바로 적용됩니다. 이전 버전에서 바꿔 둔 목록은 업그레이드할 때 적용됩니다.

---

> ```bash
> docker compose pull && docker compose up -d
> ```

---

## Fixes

- A 403 returned by the site itself showed in the logs as a bot-filter block, so a site answering Google's ad crawler with 403 looked as if NPG had blocked it. Only requests NPG blocks itself are labelled bot filter now.
- Saving the bot lists under Settings → Bot Filter did not reach nginx right away. Saving now applies them to every host. Lists changed on an earlier version are applied when you upgrade.
