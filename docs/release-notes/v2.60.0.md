## ⚠️ 업그레이드 전에 알아둘 것

- **경로를 한정한 예외는 이제 요청이 실제로 가는 경로로 판정합니다.** WAF 규칙의 "이 경로에서만" 예외, exploit 규칙의 URI 예외와 Block Exploits 예외, ForwardAuth 우회 경로, ACME·챌린지 경로 예외가 `/api/../admin`, `%2e%2e`, `..;`처럼 꾸민 경로로 다른 곳에 닿는 요청에는 적용되지 않습니다. 이런 경로로 다른 페이지의 보안 검사를 건너뛸 수 있었습니다. 브라우저는 이런 경로를 보내지 않아 평소 사용에는 영향이 없고, ForwardAuth 우회 경로로 이런 요청이 오면 403을 돌려줍니다.
- **exploit 규칙 URI 예외와 Block Exploits 예외는 디코딩된 경로로 비교합니다.** 로그에서 복사한 `%20`이나 한글 인코딩 경로도 그대로 맞고, 패턴 속 `%HH`는 디코딩된 글자와도 맞습니다. 퍼센트 인코딩이 든 예외가 있다면 한 번 확인해 주세요.
- **토큰이 에러 메시지에 남던 문제를 고쳤습니다.** 인증서 DNS-01(DuckDNS)과 알림(Telegram·Discord·웹훅) 실패 메시지에 토큰이나 웹훅 주소가 그대로 저장돼 화면에 보일 수 있었습니다. 업그레이드할 때 인증서·알림 쪽에 저장된 것은 한 번 가리지만, 이전에 쌓인 시스템 로그와 컨테이너 로그에는 남아 있을 수 있습니다. 에러에서 `token=`, 봇 토큰, 웹훅 주소를 본 적이 있다면 그 토큰을 재발급하세요.

## 새 기능

- 봇 필터의 허용 UA를 특정 경로에만 적용할 수 있습니다: `okhttp @ /api` (#313). 기존 허용 목록에 공백으로 띄운 `@`가 있는 줄은 이제 경로 지정으로 읽힙니다.

## 고침

- 봇 필터 목록에 `;`가 든 UA(실제 UA 문자열 대부분)를 넣으면 저장이 실패하고, 전역 목록이면 모든 호스트의 설정 갱신이 막히던 문제. 주석만 남은 목록이 모든 방문자를 차단하던 문제.
- 전역 WAF를 따르는 호스트를 저장하면 그 호스트의 WAF 예외가 빠지던 문제.
- 요청에 `?a=.js`처럼 정적 파일 확장자를 끼워 넣으면 레이트 리밋을 피할 수 있던 문제.
- 대시보드 지도에 호주·벨기에 등 일부 나라 통계가 보이지 않던 문제. 지도에 모양이 없는 작은 나라는 점으로 표시합니다. (#316)
- IPv6 포워드 호스트(`fd00::1`)가 저장되지 않던 문제. `[fd00::1]`처럼 대괄호를 넣어도 됩니다. (#314)
- DDNS 동기화에서 제공자가 인증을 거부하면 500 대신 400과 이유를 돌려줍니다. DuckDNS 토큰이 DDNS 에러에 보이던 문제도 고쳤습니다. (#312)
- NPG 화면을 WAF가 켜진 프록시 호스트로 열 때 WAF 차단이 "권한 없음"으로 표시되던 문제. (#307)

## ⚠️ Read before upgrading

- **Path-limited exemptions are now decided on the path the request actually reaches.** WAF "this path only" exclusions, exploit-rule URI exclusions and Block Exploits exceptions, ForwardAuth bypass paths and the ACME/challenge exemptions no longer apply to requests disguised as `/api/../admin`, `%2e%2e` or `..;` that reach somewhere else. Such paths could skip the security checks of other pages. Browsers never send them, so normal use is unaffected; a ForwardAuth bypass path answers such a request with 403.
- **Exploit-rule URI exclusions and Block Exploits exceptions compare against the decoded path.** A path copied from the log with `%20` or encoded non-ASCII characters still matches, and a `%HH` in a pattern also matches the decoded character. If you have exceptions with percent-encoded characters, give them a quick check.
- **Tokens no longer stay in error messages.** Failed DNS-01 issuance (DuckDNS) and failed notifications (Telegram, Discord, webhooks) stored the token or webhook URL in error text shown in the UI. Copies stored with certificates and notifications are masked once on upgrade; older system log entries and container logs may still hold them. If you ever saw `token=`, a bot token or a webhook URL in an error, regenerate that token.

## Added

- Bot filter allowed user agents can be limited to paths: `okhttp @ /api` (#313). An existing allowed-agent line with a space-separated `@` is now read as a path list.

## Fixed

- A bot filter list containing `;` (most real user-agent strings) failed to save, and a global list blocked config updates for every host. A list holding only comments blocked every visitor.
- Saving a host that follows the global WAF dropped its WAF exclusions.
- Slipping a static file extension into a request (such as `?a=.js`) let it skip rate limiting.
- The dashboard map showed no statistics for some countries (Australia, Belgium, ...). Small countries without a shape on the map are drawn as dots. (#316)
- An IPv6 forward host (`fd00::1`) could not be saved. The bracketed form `[fd00::1]` is accepted too. (#314)
- DDNS sync answers 400 with the reason instead of 500 when the provider rejects the credentials, and the DuckDNS token no longer shows in DDNS errors. (#312)
- With the NPG UI behind a WAF-enabled proxy host, a WAF block was shown as "Your role does not allow this action". (#307)
