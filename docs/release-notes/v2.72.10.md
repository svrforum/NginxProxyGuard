## 새 기능

- 접근 로그 필터의 차단 사유에 "차단됨 (모든 사유)"를 추가했습니다. 사유와 관계없이 막힌 요청만 모아 볼 수 있고, WAF에 막힌 요청도 포함됩니다. 그동안 목록에 없던 익스플로잇 차단, URI 차단, 접근 거부, 클라우드 챌린지·차단도 고를 수 있습니다. (#407)

---

> ```bash
> docker compose pull && docker compose up -d
> ```

---

## New

- The access log's block reason filter has a new "Blocked (any reason)" option. It lists only the requests that were blocked, whatever the reason, WAF blocks included. Exploit, URI block, access denied and the two cloud provider reasons, missing from the list until now, can be picked as well. (#407)

> docker compose pull && docker compose up -d
