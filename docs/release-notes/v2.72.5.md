## 수정

- CAPTCHA 챌린지를 통과한 뒤 돌아갈 주소를 검사하는 부분에 빈틈이 있어, 조작한 챌린지 링크로 방문자를 다른 사이트로 보낼 수 있었습니다. 같은 호스트가 아닌 주소는 이제 사이트 첫 화면(`/`)으로 보냅니다.

---

> ```bash
> docker compose pull && docker compose up -d
> ```

---

## Fixes

- The check on where to send a visitor after passing a CAPTCHA challenge had a gap, so a crafted challenge link could send them to another site. Addresses on a different host now go to the site root (`/`) instead.
