## ✨ Improvements

- **DDNS: choose whether to delete the DNS records at the provider when you turn DDNS off or delete a host.** Switching DDNS off in a proxy host's settings, or deleting a host that used DDNS, previously removed the records from NPG only — the live A record kept pointing at your server. Both now ask, the same way the DDNS record menu does, and list exactly which hostnames are affected. Turning DDNS off suggests removing them (checked); deleting a host does not (unchecked), so a routine deletion never drops your public DNS by accident. Providers that cannot delete records say so instead of offering the choice. (#219)

- **Certificates → DDNS: the Cloudflare proxy indicator now appears where the setting lives.** The orange cloud is shown on each DDNS record, read from the record itself, so it reflects what was actually sent to Cloudflare. It only appears for Cloudflare records, where the proxy setting means something. The indicator on the certificate list is unchanged. (#220)

## 🐛 Fixes

- **Dependency updates**, including a fix for a denial-of-service advisory in a build-time dependency (`brace-expansion`, GHSA-mh99-v99m-4gvg) and the Prometheus client library. (#214, #217, #218)

## 📈 For operators who scrape `/metrics`

The Prometheus client library upgrade adds three `# UNIT` metadata lines (`go_gc_gogc_percent`, `go_gc_gomemlimit_bytes`, `go_sched_gomaxprocs_threads`) to scrapes negotiated as OpenMetrics. Metric names, labels and values are unchanged, so existing Grafana dashboards and alert rules keep working as-is.

> docker compose pull && docker compose up -d
> ```
