## 🚀 New: Saved log filter presets + CIDR exclude

Tired of re-typing the same exclude filters every time you open the logs? This release makes the access-log viewer's filters reusable. (#210)

- **Save a filter preset.** Set up your filters (including the exclude filters), open the **Advanced Filters** panel, and click **Save current filters** to store them under a name. Re-apply any saved preset in one click from the presets dropdown, or delete presets you no longer need. Presets are shared across admins.

- **Exclude whole IP ranges (CIDR).** The IP exclude filter now accepts CIDR ranges, not just single IPs — e.g. add `10.0.0.0/8` or `192.168.0.0/16` to hide all internal-network traffic, or a monitoring host's subnet, in one entry. Plain IPs still work as before; invalid entries are ignored.

Together these let you keep something like a **"hide internal subnet + monitoring host"** preset and apply it whenever the access log gets noisy, so real traffic is easy to spot.
