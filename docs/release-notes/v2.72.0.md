## 새 기능

- TCP/UDP 스트림 호스트의 연결 기록을 로그 → 스트림 탭에서 볼 수 있습니다. 접속 IP, 프로토콜, 상태, 보낸 바이트, 접속 시간, 백엔드가 나옵니다. 스트림 원본 로그는 접근 로그와 같은 폴더(`/etc/nginx/logs/stream_raw.log`)에 쌓이고 같은 보관·회전 설정을 따릅니다. UDP처럼 기록이 많은 호스트는 로그 → 수집 규칙에서 저장하지 않게 할 수 있습니다. 트래픽·대시보드 통계에는 아직 들어가지 않습니다. (#392)

## 변경

- WAF 규칙 941310(US-ASCII Malformed Encoding XSS Filter)을 기본으로 끕니다. 한글·일본어·중국어·러시아어·독일어 같은 글자와 HTML 태그가 함께 들어간 글(블로그·게시판 글쓰기)을 공격으로 오인해 막거나, WAF 자동 차단으로 글쓴이 IP를 차단하던 규칙입니다. 이 규칙이 막는 공격은 옛날 인터넷 익스플로러에서만 통합니다. 필요하면 WAF / 차단관리 → WAF 정책 설정 → 전역 정책 탭의 규칙 목록에서 다시 켤 수 있고, 다시 켠 설정은 이후 업그레이드에서도 유지됩니다.

## New features

- TCP/UDP stream hosts' connections now show in Logs → Stream: client IP, protocol, status, bytes sent, session time and backend. The raw stream log sits next to the access log (`/etc/nginx/logs/stream_raw.log`) and follows the same retention and rotation. A busy host (UDP, for one) can be left out in Logs → Collection rules. Traffic and dashboard statistics don't include them yet. (#392)

## Changes

- WAF rule 941310 (US-ASCII Malformed Encoding XSS Filter) is now off by default. It mistook posts that mix HTML tags with Korean, Japanese, Chinese, Russian, German and similar text (blog and forum posts) for attacks, blocking them or getting the author's IP auto-banned. The attack it stops only ever worked on old Internet Explorer. You can turn it back on in the rule list under WAF / Blocking → WAF Policy Settings → Global Policies, and that choice is kept across upgrades.
