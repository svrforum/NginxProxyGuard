## 고침

- 로그 화면 필터의 자동완성 목록(호스트, IP, URI, User-Agent, 국가, 메서드)이 비어 나오던 문제. 설치 직후처럼 로그가 없을 때 로그 화면을 열면 빈 목록이 1시간 동안 남아, 그사이 들어온 로그가 목록에 나오지 않았습니다.

> 알려 주신 **@four2mis** 님(#340) 감사합니다.

---

> ```bash
> docker compose pull && docker compose up -d
> ```

## Fixed

- The autocomplete lists in the logs page filters (hosts, IPs, URIs, user agents, countries, methods) could come up empty. Opening the logs page while there were no logs yet, as right after installing, kept the empty list for an hour, so logs that arrived in the meantime did not show up in it.

> Thanks to **@four2mis** for reporting it (#340).
