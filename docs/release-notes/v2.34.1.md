## 🔒 Security: nginx updated to 1.30.4

The proxy image now builds nginx **1.30.4** instead of 1.30.2, picking up five upstream fixes. (#226)

| Advisory | Issue | Severity |
|---|---|---|
| CVE-2026-42533 | Buffer overflow when using `map` with a regex | **major** |
| CVE-2026-60005 | Memory disclosure in `ngx_http_slice_module` | medium |
| CVE-2026-56434 | Use-after-free in `ngx_http_ssi_module` | medium |
| CVE-2026-42055 | Buffer overflow in the proxy_v2 and gRPC modules | medium |
| CVE-2026-48142 | Buffer overread in `ngx_http_charset_module` | low |

The first one matters most here: NPG generates `map` blocks with regular expressions for rate limiting and GeoIP, so that code path is on by default.

**"NGINX Rift" (CVE-2026-42945) never affected NPG.** It was fixed upstream in 1.30.1, and NPG has shipped 1.30.1 or newer since v2.13.14. The same goes for the HTTP/3 advisory CVE-2026-42530, which only applies to the 1.31.x mainline branch that NPG does not use.

Nothing changes in configuration or behaviour — same modules, same OpenSSL, same ModSecurity 3.0.15 and OWASP CRS 4.26.0.

> ⚠️ **This release changes the nginx image**, so a plain `docker compose pull` of the api and ui alone is not enough:
> ```bash
> docker compose pull && docker compose up -d
> ```
> Confirm afterwards with:
> ```bash
> docker exec npg-proxy nginx -v
> ```
