## 수정

- 지오 챌린지나 ForwardAuth를 쓰는 호스트에서 전역 "최대 요청 크기"보다 큰 업로드가 401(Geo Block)로 거절되었습니다. 호스트의 "클라이언트 최대 본문 크기"를 더 크게 잡아 두었거나, 챌린지 대상이 아닌 방문자가 보낸 업로드여도 마찬가지였습니다. 이제 호스트에 설정한 크기까지 업로드됩니다. (#402, #404)

## Fixes

- On a host using the geo challenge or ForwardAuth, an upload larger than the global "max request size" was refused with 401 (Geo Block). This happened even when the host's own "client max body size" was larger and the visitor was never challenged. Uploads now go through up to the host's limit. (#402, #404)
