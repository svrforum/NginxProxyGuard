## 고침

- **HTTP/3가 간헐적으로 멈췄다가 HTTP/2로 떨어지던 문제.** nginx 워커가 여러 개일 때 하나의 UDP 소켓을 나눠 쓰느라, 한 연결의 패킷이 엉뚱한 워커로 가고 있었습니다. 업데이트만 하면 적용되며 프록시 재시작은 필요 없습니다.
- **WAF 규칙을 예외했는데 계속 차단되던 문제.** WAF는 여러 규칙의 점수를 합쳐 차단하는데 이벤트 화면에는 그중 하나만 보여서, 그 규칙만 꺼도 다음 요청이 다른 규칙으로 다시 막혔습니다. 이제 차단에 관여한 규칙을 전부 보여주고 한 번에 끌 수 있습니다. 이미 예외된 규칙은 따로 표시됩니다.

---

> ```bash
> docker compose pull && docker compose up -d
> ```

## Fixed

- **HTTP/3 stalled intermittently and fell back to HTTP/2.** With several nginx workers sharing one UDP socket, packets for a connection reached workers that did not own it. Applied by the update alone; no proxy restart needed.
- **A WAF rule stayed blocking after you disabled it.** The WAF blocks on the combined score of several rules, but the event screen showed only one, so disabling it left the next request blocked under another. The screen now lists every rule that contributed and disables them together, marking the ones already excluded.
