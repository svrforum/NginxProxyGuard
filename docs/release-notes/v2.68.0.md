## 새 기능

- 상단에 nginx 버전과 인스턴스 이름을 표시합니다(#369). 이름은 설정 > 전역 설정 > Advanced 탭에서 정하고, 브라우저 탭 제목에도 붙어 NPG를 여러 대 쓸 때 구분하기 쉽습니다.
- IP 차단 목록에 주소마다 국가를 표시합니다(GeoIP를 쓰는 경우, #369).
- 대시보드 상위 국가 목록에서 국가를 누르면 그 국가로 걸러진 접근 로그가 열립니다(#367).

## 고침

- 대시보드의 "WAF 차단"이 항상 0이던 문제(#369). v2.13.18부터 WAF 차단을 세지 못했고 "차단된 요청"에도 빠져 있었습니다. 업그레이드한 뒤에는 지난 24시간의 차단까지 셉니다.
- 접근 목록 화면에 처음 20개만 보이고, 호스트 편집의 접근 목록 선택에는 100개까지만 나오던 문제(#369).
- WAF를 "상속"으로 둔 호스트의 WAF 배지가 실제 전역 설정과 다르게 나오던 문제(#369).
- 대시보드 지역별 비율의 합이 100%가 되지 않던 문제(#367). 사설·LAN 주소처럼 국가를 알 수 없는 요청을 "LAN / 미확인"으로 따로 보여 줍니다.
- WAF 로그에서 긴 호스트 이름이 IP 칸에 겹치던 문제(#368).
- 다크 모드에서 트래픽 그래프의 날짜·시간이 보이지 않던 문제(#370).

> 알려 주신 **@theAmberLion**(#369), **@q20021410**(#368), **@piojan**(#367, #370) 님 감사합니다.

## New

- The header shows the nginx version and an instance name (#369). Set the name under Settings > Global Settings > Advanced; it is added to the browser tab title too, so several NPG installs are easy to tell apart.
- The IP ban list shows each address's country (with GeoIP set up, #369).
- A country in the dashboard's top countries list opens the access logs filtered to it (#367).

## Fixed

- The dashboard's "WAF Blocked" counter always read 0 (#369). Since v2.13.18 WAF blocks went uncounted, and "Blocked Requests" left them out too. After upgrading, blocks from the last 24 hours are counted as well.
- The access list page showed only the first 20 lists, and the host editor's access list picker only the first 100 (#369).
- The proxy host list's WAF badge did not follow the global setting for hosts set to "Inherit" (#369).
- The dashboard's traffic by region did not add up to 100% (#367). Requests with no country, such as private and LAN addresses, now have a "LAN / Unknown" row.
- A long host name ran over the IP column in the WAF logs (#368).
- In dark mode, the date and time on the traffic charts were unreadable (#370).
