## 🌐 관리자 감사 로그 다국어 표시 수정 (#196)

영어 UI를 사용할 때 **관리자 감사(Admin Audit)** 로그의 "Activity" 컬럼이 한국어(`로그인`, `설정 변경` 등)로 표시되던 문제를 수정했습니다.

### 🐛 버그 수정
- **감사 로그 활동 라벨이 UI 언어를 따르도록 수정**: 이제 영어 UI에서는 `Login`, `Settings Updated`, `Proxy Host Updated`처럼 영어로, 한국어 UI에서는 기존대로 한국어로 표시됩니다.
  - 로그인/로그아웃, 프록시 호스트·인증서·WAF·백업·API 토큰 등 모든 활동 유형에 적용됩니다.
