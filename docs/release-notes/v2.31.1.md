## 🐛 전역 WAF 기본값 켤 때 발생하던 오류 수정 (#202)

v2.31.0에서 추가된 **전역 WAF 기본값(Global Default WAF)** 을 켤 때, 이미 "상속(Inherit)" 상태로 설정해 둔 호스트가 있으면 저장이 거부되던 문제를 수정했습니다.

### 무엇이 문제였나

특정 순서에서만 재현되던 버그입니다.

1. 호스트의 WAF를 **상속(Inherit)** 으로 먼저 설정 (이때 전역 기본값은 꺼져 있음)
2. 이후 **전역 WAF 기본값을 켬**

이 순서로 조작하면, 상속 중이던 호스트의 실효 WAF 설정은 "켜짐"으로 바뀌지만 해당 호스트의 ModSecurity 설정 파일이 새로 생성되지 않아, nginx 설정 검사(`nginx -t`)가 존재하지 않는 파일을 참조하며 실패했습니다. 그 결과 전역 기본값 켜기 자체가 거부되었습니다.

### 수정 내용

전체 설정 동기화 과정에서, 저장된 호스트 값이 아니라 **전역 기본값이 반영된 실효(resolved) 호스트 값**을 기준으로 per-host ModSecurity 파일을 생성하도록 바로잡았습니다. 이제 상속 호스트가 전역 기본값을 따라 WAF가 켜지면 해당 설정 파일도 함께 생성되어 검사가 통과합니다.

### 🧪 품질
- 이 순서(상속 먼저 → 전역 나중)를 그대로 재현하는 Playwright 회귀 테스트를 추가해, 동일 문제의 재발을 막습니다.
