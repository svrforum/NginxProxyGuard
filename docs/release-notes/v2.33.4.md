## 🐛 Bug Fixes & Improvements

- **DDNS (Cloudflare): setting changes on existing records now apply.** Toggling the Cloudflare proxy (orange cloud) or changing the TTL on a hostname that already had a DNS record was silently dropped — the sync compared only the IP address and skipped the update when the IP was unchanged. NPG now compares the proxy status and TTL as well, updates existing managed records when a host's proxy setting changes, and re-syncs immediately after an edit instead of waiting for the next IP change. This applies to both the host's DDNS settings and the DDNS records menu. (#215)

- **DDNS: choose whether to remove the record from the provider on delete.** Deleting a DDNS record now asks whether to also remove the live record at the provider (e.g. the Cloudflare A record). Leave it checked to delete everywhere (previous behavior); uncheck it to remove the record from NPG only and keep the DNS entry at the provider. (#215)

- **Certificates: Cloudflare proxy indicator on linked hosts.** The certificate list and detail views now show an orange-cloud icon next to a linked host that uses Cloudflare DDNS with the proxy enabled, so you can see the proxy state at a glance. (#216)
