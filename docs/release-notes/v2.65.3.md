## 보안

- Cloudflare Tunnel에 쓰는 cloudflared를 2026.10.5로 올렸습니다. 이전 버전이 안전하지 않은 것으로 밝혀진 인증서를 신뢰해서, Cloudflare가 터널 사용자에게 2026.10.2 이상으로 올리라고 안내한 업데이트입니다.

## 고침

- 전역 GeoIP 기본값에서 챌린지 모드를 켜고 저장하면 오류(500)가 나던 문제. ForwardAuth를 켠 호스트가 있으면 설정 검사가 실패했고, 그 호스트는 접속되지 않았습니다. 이제 ForwardAuth를 켠 호스트는 챌린지 대신 차단(403)하며, 그렇게 내려간 호스트는 업그레이드하면 다시 열립니다.
- DDNS 레코드를 만들거나 고칠 때 없는 DNS 제공자를 지정하면 500 대신 400과 이유를 돌려줍니다.

> 알려 주신 **@ydrob** 님(#341, #342)과 **@four2mis** 님(#344) 감사합니다.

> docker compose pull && docker compose up -d
> ```

## Security

- cloudflared, which runs Cloudflare Tunnel, is now 2026.10.5. Older versions trust certificates now known to be unsafe, so Cloudflare asked tunnel owners to move to 2026.10.2 or later.

## Fixed

- Saving the global GeoIP default with challenge mode on failed with an error (500) when a host had ForwardAuth on: the config check failed and that host went offline. Hosts with ForwardAuth now block (403) instead of showing the challenge, and upgrading brings such a host back.
- Creating or editing a DDNS record with a DNS provider that does not exist now returns 400 with the reason instead of 500.

> Thanks to **@ydrob** (#341, #342) and **@four2mis** (#344) for the reports.
