## 🛡️ Security & Bug Fixes

- **Go standard-library security fixes.** The API is now built with Go 1.26.5, resolving three reachable Go stdlib vulnerabilities (crypto/tls ECH, net/textproto, crypto/x509). `govulncheck` reports zero affecting vulnerabilities after the bump. Other entries in third-party vulnerability scans (x/crypto, x/sys, "SQL injection" in parameterized queries, `InsecureSkipVerify` in the upstream diagnostics testers, test-fixture passwords) were verified as not reachable / false positives. (#211)

- **Non-existent subdomains over Cloudflare Tunnel are no longer served.** When all traffic is routed through the tunnel, a request for a subdomain that has no configured proxy host was leaking the welcome page (and cluttering the access log). It now follows your **Settings → Direct IP Access Action** (e.g. silently closed with 444). (#212)

> Pull the **api** image and recreate:
> ```bash
> docker compose pull && docker compose up -d
> ```
