## 고침

- 접근 로그를 시간순으로 보면 몇 초씩 순서가 뒤섞이던 문제(#373). 이제 요청 시각 순으로 정렬합니다.
- 로그 시각을 24시간제로 표시합니다(#373).
- SSO 제공자를 추가할 때 다른 제공자를 골라도 표시 이름과 식별자가 처음 고른 제공자로 남던 문제(#372).
- API로 로그 목록을 `sort_by=timestamp`로 받으면 `next_cursor` 대신 `page`로 넘깁니다. 첫 페이지가 돌려준 `as_of`를 다음 페이지에 함께 보내면 새로 쌓인 로그 때문에 페이지가 밀리지 않습니다.

> 알려 주신 **@piojan**(#373), **@mortal224455**(#372) 님 감사합니다.

> docker compose pull && docker compose up -d
> ```

## Fixed

- Access logs sorted by time could be out of order by several seconds (#373). They are now sorted by request time.
- Log times are shown on a 24-hour clock (#373).
- When adding an SSO provider, picking another provider kept the first one's display name and identifier (#372).
- In the API, the log list with `sort_by=timestamp` pages with `page` instead of `next_cursor`. Send the `as_of` the first page returned with the next pages, so logs stored meanwhile do not shift them.

> Thanks to **@piojan** (#373) and **@mortal224455** (#372) for the reports.
