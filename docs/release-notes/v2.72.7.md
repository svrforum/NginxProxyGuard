## 수정

- 신뢰 프록시를 비워 둔 설치에서는 전역 Fail2ban을 켤 수 없었습니다. NPG 앞에 CDN이나 프록시 없이 바로 접속받는 서버라면, 이제 그 내용을 확인하는 칸에 체크하고 켤 수 있습니다. CDN 뒤에 있다면 지금처럼 신뢰 프록시를 먼저 지정하세요. (#400)
- 영어 UI의 날짜가 미국식(11/18/2026)으로 나와 다른 나라에서는 일/월로 읽혔습니다. 이제 2026-11-18처럼 연도부터 씁니다. 한국어 UI는 그대로입니다. (#401)

## Fixes

- The global Fail2ban jail could not be switched on while Trusted Proxies was empty. A server that visitors reach directly, with no CDN or proxy in front, can now switch it on by ticking a box that confirms this. Behind a CDN, set Trusted Proxies first as before. (#400)
- The English UI wrote dates in US order (11/18/2026), which reads as day/month in most other countries. Dates are now written year first, like 2026-11-18. The Korean UI is unchanged. (#401)
