## 🛡️ 보안 옵션 전역 기본값 + 호스트별 3단계 오버라이드 (#198)

프록시 호스트가 많은 홈서버 운영자를 위해, 6가지 보안 옵션을 **한 번만 설정하면 모든 호스트에 적용**되도록 하는 전역 기본값(Global Default) 기능이 추가되었습니다. 각 호스트는 필요할 때만 예외를 두면 됩니다.

### ✨ 새로운 기능

**전역 기본값을 지원하는 6가지 보안 옵션**
- GeoIP 국가 제한
- 봇 필터
- 보안 헤더(Security Headers)
- 클라우드 제공자 차단(Cloud Provider Blocking)
- 요청 속도 제한(Rate Limit)
- WAF(ModSecurity) 모드 · Paranoia Level

**호스트별 3단계 선택 (상속 / 재정의 / 비활성화)**
- **상속(Inherit)** — 전역 기본값을 그대로 따릅니다. 전역 설정만 바꾸면 상속 중인 모든 호스트에 한 번에 반영됩니다.
- **재정의(Override)** — 이 호스트만 별도 값을 사용합니다(기존 방식).
- **비활성화(Disable)** — 전역 기본값이 켜져 있어도 이 호스트에서는 해당 보안 옵션을 끕니다.

각 옵션의 전역 기본값은 **`WAF / 차단` 메뉴 안의 전역 설정 화면**에서 관리합니다.

### 🔒 업그레이드 시 동작 변화 없음
모든 전역 기본값은 **기본적으로 꺼진 상태(off)**로 도입됩니다. 따라서 이번 버전으로 업그레이드해도 기존 호스트의 동작은 전혀 바뀌지 않습니다. 전역 기본값을 직접 켤 때만 적용이 시작됩니다.

> **참고:** 전역 기본값을 켜면, 지금까지 해당 옵션을 따로 설정하지 않았던(= 상속 상태의) 호스트들이 전역값을 따라가기 시작합니다. 특정 호스트만 계속 꺼두려면 그 호스트에서 **비활성화(Disable)**를 선택하세요.

> **WAF 전역 변경 안내:** WAF(ModSecurity) 전역 기본값을 바꾼 경우, 규칙이 다시 로드되도록 프록시 재시작 후 완전히 적용됩니다.

### 🧪 품질
- 신규/업그레이드 설치 경로 모두에서 마이그레이션 검증(기존 호스트는 안전한 기본값으로 자동 채움).
- 전역 관리 화면과 호스트별 3단계(상속·재정의·비활성화) 동작을 Playwright E2E로 검증.
