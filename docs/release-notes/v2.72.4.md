## 수정

- 프록시 호스트 폼에 입력하던 중 Esc, ×, 취소를 누르면 묻지 않고 닫혀 입력이 사라졌습니다. 바뀐 내용이 있으면 먼저 확인합니다.
- 프록시 호스트 삭제, 켜기/끄기, 즐겨찾기가 실패해도 화면에 아무 표시가 없었습니다. 이제 목록 위에 실패 사유를 보여주고, 목록을 불러오지 못하면 다시 시도 버튼이 나옵니다.
- 휴대폰 폭에서 상단 메뉴의 트래픽·로그·설정이 화면 밖에 숨어 있었습니다. 메뉴가 두 줄로 접힙니다.
- 브라우저를 200%로 확대하면 호스트 폼의 저장 버튼이 화면 밖으로 밀렸습니다.

## 개선

- 대시보드 색 타일, 회색 보조 글씨, 꺼진 호스트 행의 글자를 더 잘 읽히게 했습니다.
- 로그인, 대시보드, 호스트 목록과 폼을 키보드와 스크린리더로 쓸 수 있게 했습니다.
- 백엔드 상태와 WAF 모드(차단/탐지)를 색뿐 아니라 글자로도 보여줍니다.
- 한국어 화면에 섞여 있던 영어 문구와 봇 분류 값(`other`, `bad_bot` 등)을 번역했습니다.

## Fixes

- Pressing Esc, × or Cancel while filling in the proxy host form closed it without asking, losing what you typed. It now asks first when something changed.
- A failed delete, enable/disable or favorite on a proxy host showed nothing. The reason now appears above the list, and a list that fails to load offers a Retry button.
- On a phone-width screen, Traffic, Logs and Settings in the top menu were hidden off screen. The menu now wraps to two lines.
- At 200% browser zoom, the host form's Save button was pushed off screen.

## Improvements

- Dashboard tiles, grey secondary text and rows of disabled hosts are easier to read.
- Login, the dashboard, the host list and the host form work with a keyboard and a screen reader.
- Backend health and WAF mode (blocking/detection) are shown in words, not by color alone.
- English text and raw bot categories (`other`, `bad_bot`, …) left in the Korean UI are translated.
