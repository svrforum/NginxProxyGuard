## 새 기능

- 트래픽 화면(인증서와 로그 사이): 프록시 호스트별 요청 수와 응답 바이트를 1시간·24시간·7일·30일·직접 지정한 기간으로 보고, 호스트를 비교하고, CSV로 내보낼 수 있습니다. 업그레이드 뒤 백그라운드에서 보관 중인 로그(최대 90일)로 호스트별 기록을 최근 것부터 채웁니다(7일치 30분, 30일치 2시간 안팎). 아직 채우지 못한 시간과, 호스트에 속하지 않는 트래픽, 로그가 이미 지워진 과거 합계는 "미분류"로 보입니다.

## 고침

- 설정을 다시 적용할 때마다 이전 nginx 워커가 쌓이던 문제(#358). WebSocket·gRPC·긴 다운로드를 붙잡은 워커가 끝나지 않고 남아 메모리와 소켓을 차지했고, 쌓이면 설정 적용이 실패해 호스트가 Error로 표시될 수 있었습니다. 이제 이전 워커는 최대 4분 뒤 연결을 닫고 정리됩니다(전역 설정 > Worker에서 조정, 0이면 예전처럼 끝까지 기다림). 업그레이드 전부터 남아 있던 워커는 nginx를 한 번 재시작하면 정리됩니다: `docker compose restart nginx`
- Let's Encrypt 인증서마다 리로드 때 `"ssl_stapling" ignored` 경고가 찍히던 문제(#359). Let's Encrypt는 2025년부터 인증서에 OCSP 주소를 넣지 않습니다. 이런 인증서를 쓰는 호스트는 OCSP stapling을 끕니다.
- 챌린지 검증 API에 없는 호스트 ID를 보내면 500 대신 404를 돌려줍니다(#356). 폼 방식 검증은 5초마다 새로고침하는 503 페이지가 끝없이 반복되던 것을 이전 페이지로 돌려보냅니다.
- SSO 제공자의 그룹 클레임 이름이 64자를 넘으면 500 대신 400을 돌려줍니다(#353).
- 새 서버(새로 설치한 NPG)에 백업을 복원하면 "성공"으로 나오지만 전역 설정이 하나도 복원되지 않던 문제.
- 익스플로잇 룰 예외와 WAF 전역 룰 끄기에 "누가 껐는지"가 비어 있거나 항상 admin으로 저장되던 문제.

## New

- Traffic page (between Certificates and Logs): requests and response bytes per proxy host over 1 hour, 24 hours, 7 days, 30 days or a custom range, with host comparison and CSV export. After the upgrade, per-host history is filled in the background from the retained logs (up to 90 days), newest first: about 30 minutes for 7 days, 2 hours for 30 days. Hours not filled yet, traffic not tied to a proxy host, and history whose logs were already deleted show as "Unclassified".

## Fixed

- Old nginx workers piled up with every configuration reload (#358). A worker holding a WebSocket, a gRPC stream or a long download never exited, so the workers kept memory and sockets, and once enough piled up reloads failed and hosts could be marked Error. Old workers now close their connections and exit after at most 4 minutes (Global Settings > Worker; 0 keeps the old wait-forever behaviour). Workers left from before the upgrade go away when nginx restarts once: `docker compose restart nginx`
- Every Let's Encrypt certificate logged an `"ssl_stapling" ignored` warning on each reload (#359). Let's Encrypt stopped putting OCSP URLs in its certificates in 2025; hosts using such a certificate now turn OCSP stapling off.
- The challenge verify API answers 404 instead of 500 for a proxy host ID that does not exist (#356). The form-based verify sends the visitor back instead of a 503 page that reloaded itself every five seconds forever.
- An SSO provider's group claim name longer than 64 characters is 400 instead of 500 (#353).
- Restoring a backup onto a fresh install reported success but restored none of the global settings.
- Exploit rule exclusions and global WAF rule exclusions recorded who disabled the rule as empty or always "admin".

## Security

- Built with Go 1.27.3 (crypto/x509 security fix); curl and brotli in the UI image are updated to their patched versions.
