## 🛡️ Bug Fix

- **CIDR ranges can now be typed into the log IP filter fields.** In v2.33.0 the backend accepted CIDR exclude ranges, but the IP filter input (which autocompletes exact IPs from your logs) swallowed the Enter key when you typed a range like `192.168.1.0/24`, so it never got added. The value is now committed even when it matches no autocomplete suggestion. (#210)
