## 🔐 보안 — 2FA를 쓰신다면 꼭 읽어 주세요

### TOTP 비밀키가 외부 QR 서비스로 전송되던 문제

2단계 인증을 설정할 때 화면에 뜨는 QR 코드는 단순한 그림이 아닙니다. 그 안에는 계정의 **TOTP 비밀키가 통째로** 들어 있습니다.

```
otpauth://totp/...?secret=<TOTP 비밀키>&issuer=...
```

기존 화면은 이 문자열 전체를 **외부 QR 생성 서비스**(`api.qrserver.com`)의 주소 뒤에 붙여 이미지를 불러왔습니다. 즉 **2FA를 켜는 순간 비밀키가 제3자 서버로 전송**됐고, 주소 파라미터라 상대 서버의 접근 로그에도 남습니다.

이 비밀키는 2FA를 끄거나 다시 등록하기 전까지 계속 유효합니다. 이 값을 가진 사람은 **같은 일회용 코드를 그대로 만들어낼 수 있어**, 비밀번호까지 알려진 상황이라면 2FA가 막아야 할 것을 막지 못합니다.

이제 QR 코드는 **브라우저 안에서 직접** 그립니다. 외부로 나가는 요청이 없고, 비밀키는 사용자의 브라우저를 벗어나지 않습니다. 보안 정책(CSP)에서도 해당 도메인 허용을 지웠습니다.

### ⚠️ 이미 2FA를 쓰고 계신 분은 다시 등록해 주세요

이번 수정은 **앞으로의 전송을 막을 뿐, 이미 나간 비밀키를 무효화하지는 못합니다.**

업데이트 후 **설정 → 계정 → 2단계 인증**에서 **끄셨다가 다시 켜 주세요.** 그러면 비밀키와 백업 코드가 모두 새 값으로 교체됩니다. 인증 앱에서도 기존 항목을 지우고 새 QR로 다시 등록하시면 됩니다.

## 🔐 Security — read this if you use 2FA

### TOTP secrets were sent to a third-party QR service

The QR code shown when you set up two-factor authentication is not just a picture. It carries your account's **entire TOTP secret**:

```
otpauth://totp/...?secret=<TOTP secret>&issuer=...
```

The old screen took that whole string and appended it to an **external QR generator** (`api.qrserver.com`) to fetch the image. So **enabling 2FA transmitted the secret to a third party** — as a URL parameter, which means it also lands in that service's access logs.

The secret stays valid until 2FA is disabled or re-enrolled. Anyone holding it can **generate the same one-time codes**, so if the password is also known, 2FA stops protecting anything.

The QR code is now drawn **inside your browser**. No request leaves the machine, and the secret never goes anywhere. The allowance for that domain is removed from the Content Security Policy as well.

### ⚠️ If you already use 2FA, please re-enrol

This fix stops future transmission but **cannot invalidate a secret that has already been sent.**

After updating, go to **Settings → Account → Two-factor authentication**, **turn it off and on again.** That replaces both the secret and the backup codes. Remove the old entry from your authenticator app and scan the new QR code.
